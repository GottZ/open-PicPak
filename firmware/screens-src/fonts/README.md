# Fonts

Bundled fonts used by `gen_screens.py` to render the static setup screens. Each is used only
at build time; only the rendered bitmaps end up in the firmware.

| Font | Files | License | Source |
|------|-------|---------|--------|
| **Pixel Operator** | `po/PixelOperator-Bold.ttf`, `po/PixelOperator8.ttf` | **CC0 1.0** (public domain) | Jayvee Enaguas (HarvettFox96) — see `PixelOperator-LICENSE.txt` |
| **Perfect DOS VGA 437** | `pd/Perfect DOS VGA 437.ttf` | Free for personal & commercial use (no formal license) | Zeh Fernando, fatorcaos.com.br — see `PerfectDOSVGA437-LICENSE.txt` |

Pixel Operator is CC0. Perfect DOS VGA 437 is published as free for any use but carries no
formal license (it is an IBM-VGA recreation); details and a replacement path are in its
license note.
